1 · What it fixes

ProblemNow
The password window opened on a connection whose Test passesA query uses the account saved on the connection, as Test does. It asks only when there is nothing else to use.
"AWS portal authentication is not enabled" after entering the passwordThe window works with Admin → AWS Portal off when it is for a portal connection.
No Vault account on a Personal S3 connectionThe account picker always shows, as on Trino and Starburst. Picking an account saves the connection as "System account — no prompts". Going back to Personal clears the account.
Keys not found again on a connection with sf_ref_noSaved and looked up under the same name. This mistake came from the 456cd7380 bundle.
A wrong saved password could lock an AD accountThe same username and password the portal refused are not sent again for 5 minutes, on any path. Network failures do not count. A corrected password is tried at once.
Report StudioOn for UAT. PROD stays off. The UI chart no longer needs a ServiceAccount.

The chart lines, if you want them:

  enabled: true

# ui/templates/deployment.yaml, in place of the serviceAccountName line
      {{- with .Values.serviceAccount.name }}
      serviceAccountName: {{ . }}
      {{- end }}

# ui/values.yaml
serviceAccount:
  create: false
  name: ""
Keep the other charts' ServiceAccounts. The API chart mounts a Vault token from its account, and Vault logins may depend on these accounts. Only the UI's is unneeded.

3 · Deploy

  1. Build querystudio-api, querystudio-reports and querystudio-published-api (backend code), and the UI image (the form). No Spark image.
  2. Run ./deploy.sh uat. It installs the new qs-reports-ui release.
  3. Pods restart, so a person on a Personal connection with no saved account will be asked once more. That is expected.
  4. To set your connection: Connections → Edit → System Account (AWS Portal) → pick your Vault AD account → Test → Update.
  5. Open Report Studio at https://querystudio-reports-ui-45646.np5-gl.apaas4.claude.intranet. To remove it: set enabled: false and run helm uninstall qs-reports-ui -n 45646.
