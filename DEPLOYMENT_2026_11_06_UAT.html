  1. Take a database backup so that a rollback is exact.
  2. Unzip over the source tree of your UAT deployment, leaving out k8s as above.
  3. Delete backend/core/feed_timeout_sweeper.py.
  4. Build these images and push them with the tag you deploy:

3 · One rule that changes what admins can do

Only a Vault-based connection can now be shared. Saving or granting a shared connection is refused if it holds a typed password, uses each person's own password, or uses a System Account that is not on Vault.
  • Nothing stops running. The rule applies when a connection is saved or granted. An existing connection keeps running its feeds and reports.
  • The Connections page lists the shared connections not yet on Vault, so you can move them.
  • A private connection may keep its own password. A connection with no password to hold, such as an IAM role, Kerberos or local, passes.
  • To turn the rule off, set secrets.shared_connection_needs_vault to false.

6 · Known and not in this update

  • A published API on Snowflake is reported failing. It is not fixed, because the cause is not known yet. I need the exact error text and whether it is a SQL API or a report API.
  • New embed options are not in this zip: the Embedding sites screen, fixed values and other options per link, and detail popups on an embed. They follow in a later update.
  • A summed whole number in a CSV downloads as 1000.0.
  • A linked-tile filter does not narrow a popup's detail unless the action maps it. The popup says so.
  • Some exports and admin actions were not reaching the audit log. The fix is in the later update.

7 · Check after deploying (15 minutes)

  1. Component Health is green.
  2. On the Connections page, read the list of shared connections not yet on Vault.
  3. Open a dataset built on Snowflake SQL, preview it, and run a report on it.
  4. Embed a report with more than 1,000 rows and check the row count.
  5. On an embed or share link with a two-dates comparison, check a number tile against the report.
  6. Click a Book or a drill level and check that the popup's rows belong to it.
  7. Press Run now on a feed. It completes and the file arrives.

8 · If you must roll back

Deploy the previous images, or use helm rollback if the deployment changed through Helm. No new columns came with this update, so the database needs no change.
