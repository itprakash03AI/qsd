UAT update — 2026-10-29

Release d7e31dae6, tag release/2026-10-29-d7e31dae6. A small update on top of last night's release b012dcc99.

1 · Which zip

  • UAT runs b012dcc99 (last night's package, with or without the Snowflake hotfix): unzip Deployment_2026_10_29_d7e31dae6.zip over that source tree. It has 15 files and nothing to delete. It already includes the Snowflake hotfix.
  • UAT still runs 9572643d8 (last night's package not deployed): unzip Deployment_2026_10_28_b012dcc99.zip first, then this one.

Then rebuild the API image and the UI image and run ./deploy.sh uat. There are no new Python packages and nothing to configure. One database column, execution_checkpoints.heartbeat_at, is added by itself on the first start.

2 · What changes for users

AreaWhat users will see
A report whose server restartsIf the server running a report restarts (a deployment, a pod restart, out of memory), the report now says within about 2½ minutes: "The server running this query restarted or stopped ... press Run again", with a Run again button. Before, it looked stuck for up to 2½ hours, or said "Cancelled by user" after a deployment.
Snowflake accountThe Account field takes the full address, for example https://claude-dev_test_aws_eau.privatelink.claude.com, or the address without https://. QueryStudio connects to that PrivateLink address and uses claude-dev_test_aws_eau as the account.
AthenaThe connection test says whether the Athena workgroup limits how much a query may scan (the only limit Athena enforces). Queries no longer send a statement Athena refuses before every query.
Typed SQL on on-prem S3A path like 's3://bucket/table/...' typed into SQL on an on-prem connection now gets a clear answer: "... is the registered table trades -- write FROM trades". Before, it said "AWS access denied ... credentials expired", which was wrong. A query that names no table at all (select 41 + 1) now runs; before, it tried to read every table and was refused.

3 · Check after deploying (5 minutes)

  1. Component Health is green.
  2. The API pod log has Checkpoint heartbeat started (every 30s; a run silent 150s is failed).
  3. Your Snowflake connection, with the full address in Account: Test passes.
  4. A small report runs as before.
