2 · Deployment steps, in this order

  1. Take a database backup so that a rollback is exact.
  2. Save your own copy of k8s/querystudioapi-helm/env/uat.yaml if you edited it in UAT. Your uat.site.yaml is not in the zip and stays as it is.
  3. Unzip over the source tree of your UAT deployment (same paths).
  4. Put your own uat.yaml lines back. The new file differs from the old one in these places only:
    • hostPattern and certHostName: every address now comes from these two lines. Check they match your addresses.
    • reportsApp.enabled: false: the separate Reports app stays off.
    • One more address under cors.allow_origins, for the Reports app.
  5. Build these images and push them with the tag you deploy:
    ImageWhy

    querystudio-reports (Dockerfile.reports)Backend code
    querystudio-published-api (Dockerfile.published-api)Backend code

    The Spark job image does not need a rebuild for this update.
  6. Install the charts. From k8s/querystudioapi-helm/, run the whole script, not one chart: 
    ./deploy.sh uat

3 · What changed for you

AreaNow
NumbersA whole number has no commas: hierarchyid shows 9999993, not 9,999,993. A decimal keeps its separators. Charts and number tiles keep separators. A format set on the column wins.
Dates and text formatsEach column has a format list. The screen, PDF and Excel all follow it. A date is no longer moved a day by the browser's time zone.
Measures and dimensionsA decimal column is a measure. A whole-number column is a dimension unless its name says it is a number, such as an amount. A number named as a key, such as ..._id, is a dimension. A plain NUMBER with no scale stays a measure.
Dataset screenSemantic Layer has its own menu item, and analysts can see it. Column types, classes, relationships, conditions, Agg Awareness and drill hierarchies can be changed on screen. A dataset built from SQL shows its connection, and the connection can be changed.

4 · What to do on your existing datasets

  1. Open the dataset, go to Columns and press Detect columns. A column stored as a dimension but declared as a decimal becomes a measure and is shown again if it was hidden. The note on screen says what changed.
  2. A column already stored as a measure is never changed for you. If it looks like a key, the note names it. Change hierarchyid to dimension yourself in its row, then save.
  3. Choose a date format with the format list on the column.
The 0024-06-28 date on your Snowflake view: a format changes how a value looks, not the value. In Snowflake, run SELECT YEAR(BUSINESS_DATE). If it returns 24, the year is already wrong in the view, usually because TO_DATE(x,'DD-MON-YYYY') read a two-digit year. Fix it in the view with TO_DATE(x,'DD-MON-YY'), or CASE WHEN YEAR(d)<100 THEN DATEADD(year,2000,d) ELSE d END.

Known small issue: changing a column from measure to dimension and back gives it sum, even if it was avg before. Set it again if it matters.

5 · Optional: query pods and the Reports app

Both ship off. Leave them off for the demo unless you have already tested them. With this block off, reports run where they run today.

querystudio:
  industrialization: {enabled: true, queue_mode: true}
  query_pods:
    scaler: builtin            # or keda, which needs CHECKLIST sections 1 and 2
    reports_lane: true         # reports and report-backed APIs use the pods too
    small_run_mb: 512          # priced under this, a run stays in the API pod
    classes:                   # your sizes; empty means no pods
      s: {memory_gi: 8, min: 1, max: 4, runs_per_pod: 2}

The full commented block is in env/example.site.yaml. The Reports app needs reportsApp.enabled: true.

7 · Check after deploying (10 minutes)

  1. Component Health is green.
  2. As a non-admin, the Connections page has no New, Edit, Clone or Delete buttons.
  3. Run a report with hierarchyid: no commas in the table. A decimal column keeps them.
  4. Choose a date format on a column, then check the screen, a PDF and an Excel export.
  5. Press Detect columns on a dataset with decimals and read the note.
  6. Test your Snowflake connection with its system account.
  7. Press Run now on a feed. It completes and the file arrives.
